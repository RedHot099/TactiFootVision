# Paper draft: CVsports workshop at CVPR 2027 (xg-vendor 17)

English draft of the xg-vendor study for the CVsports workshop at CVPR 2027, built from the number-checked Polish
report next to this folder (`../REPORT.md`). Review version: anonymous, line numbers, no author names, no code link.

| File | What |
|---|---|
| `main.tex` | main paper (CVPR two-column format) |
| `supp.tex` | supplementary material, a separate PDF |
| `numbers.tex` | every number of both files as `\val{id}`; generated, do not edit |
| `claims.toml` | which report claim each `\val` id shows, with its English format |
| `figures/fig_ladder.pdf`, `figures/fig_probes.pdf` | generated by `scripts/vendor_paper_figures.py` from `results/xgv_confirmatory` |

## Build

The CVPR style kit is not in the repo. Download the CVPR author kit (the 2026 kit is
`https://github.com/cvpr-org/author-kit`, tag `CVPR2026-v1(latex)`; use the 2027 kit once it is out) and copy
`cvpr.sty` and `ieeenat_fullname.bst` into this folder (or a build copy of it). Then:

    pdflatex supp && pdflatex main && bibtex main && pdflatex supp && pdflatex main && pdflatex main

`main.tex` and `supp.tex` reference each other through `xr-hyper` (`\externaldocument`), so both need a second pass.
Checked on 2026-10-12 with TeX Live 2026 and the CVPR 2026 kit: main paper 7 pages including references (body about
6.5 pages, limit 8 excluding references), supplement 4 pages, no undefined references, no overfull boxes.

Change `\usepackage[review]{cvpr}` to `[final]`, fill `\author` and set `\codelink` (main.tex preamble) to the public
repository URL for the camera-ready. In review it prints a placeholder, because the CVPR guidelines forbid links that
identify the authors; whether an anonymous repository link (for example anonymous.4open.science) is allowed has to be
checked against the CVsports 2027 call. `\def\confName{CVPR}` and
`\def\confYear{2027}` set the review header; the workshop may ask for something else.

The StatsBomb logo is not in the repo. Its terms ask for it in anything published; drop it in as
`statsbomb_logo.pdf` and the attribution paragraph shows it.

## Numbers and figures

No number is typed into the .tex files. Every number is `\val{id}`. `claims.toml` maps each id to a claim of the
report's `claims.toml`, so it is read from the same result file with the same locator; the paper may change only the
format (English style) and the words for labels. Regenerate and check:

    ./run.sh python scripts/check_vendor_paper.py --write   # rewrite numbers.tex and the figures, then check
    ./run.sh python scripts/check_vendor_paper.py           # check only; exit 0 when everything matches

The check runs the report's own number check first (which also checks the SHA-256 of every result file against the
report's source table), then fails on a stale `numbers.tex` or figure, an unknown or unused id, a number in the text
that is not a `\val`, a spaced `\val` inside inline math, or a confirmatory or development number outside a section
labelled "confirmatory results" or "development results". The labels follow the report ("wyniki konfirmacyjne",
"wyniki rozwojowe"). The figures plot values straight from the result files; they also show values the report does
not quote (for example the fold-1 and DINOv2 probe values of the descriptive targets), all from files in the report's
source table.

## Venue facts (checked 2026-10-12)

- No CVsports 2027 call is out yet. CVPR 2027 workshops take place on 20-21 June 2027 in Seattle; workshop proposals
  are due 4 November 2026 and accepted workshops are announced on 22 December 2026, so the CVsports call cannot come
  before then. For workshops with archival proceedings, CVPR sets accepted-paper metadata due 29 March 2027 and
  camera-ready due 23 April 2027, so the CVsports 2027 paper deadline will likely fall in early March 2027 as in 2026
  (an inference, not an announcement). Source: https://cvpr.thecvf.com/Conferences/2027/CallForWorkshops
- The latest call is the 12th CVsports at CVPR 2026: paper deadline 5 March 2026 (AoE, no extensions because of the
  proceedings timeline), notification 25 March, camera-ready 10 April, submission through OpenReview. The call page
  gives no page limit or template. Source:
  https://vap.aau.dk/cvsports/12th-international-workshop-on-computer-vision-in-sports-cvsports-at-cvpr-2026/call-for-papers/
- Earlier CVsports calls state "Guidelines (same as for CVPR)" (CVsports 2020: https://vap.aau.dk/cvsports/?p=1919).
  This draft therefore follows the CVPR 2026 author guidelines: at most eight pages including figures and tables,
  extra pages only for references; double-blind review, no links that identify the authors and no link to the
  public code base; supplementary material optional and may be single-column; arXiv preprints are not publications;
  a peer-reviewed paper of more than four pages counts as a publication for dual-submission rules. Source:
  https://cvpr.thecvf.com/Conferences/2026/AuthorGuidelines
- The page limit, anonymity rules and deadline must be rechecked against the CVsports 2027 call when it appears.
